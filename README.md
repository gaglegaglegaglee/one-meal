# 한 끼의 조건

서로 다른 기관이 기록한 같은 식당의 정보를 연결해, 내 조건에 맞는 한 끼를 찾는 공공데이터 활용 웹앱입니다.

가격·위생·전통·공식 맛집 소개·반려동물 동반 안내·접근성 안내·무슬림 친화 소개, 7개 주제를 AND/OR로 조합합니다. 전국 시도/시군구, 이름·주소, 연결 주제 수로 좁히고 지도와 상세 기록을 확인할 수 있습니다.

## 실행

Node.js 20 이상에서 `npm start` 후 http://localhost:8007 을 엽니다. `npm test`로 데이터 정합성과 조건 검색을 검사합니다. 설치할 npm 패키지는 없습니다. 일반 정적 웹 서버 또는 GitHub Pages 루트에도 그대로 배포할 수 있습니다.

## 자료 구성

2026-10-16 통합 확인 기준, 식당 31,918곳, 좌표 29,275곳, 관광공사 소개문 752곳입니다. 각 자료 자체의 기준일은 서로 다릅니다. 실제 사용한 56개 자료의 기관·기준일·범위·링크는 앱의 ‘자료 이야기’와 `data/meta.json`에서 확인할 수 있습니다.

- 행정안전부 착한가격업소와 지자체 위생등급·모범음식점 자료
- 소상공인시장진흥공단 백년가게: 2022년 등재 자료
- 한국관광공사 TourAPI 음식점·반려동물 동반여행·무장애 여행정보, 지자체 맛집 소개
- 경기관광공사 무슬림 친화 음식점: 2018년 조사 기반, 2024년 공개 자료 51곳. 현재 상태 미확인, 할랄 인증을 확인하는 자료가 아닙니다.

반려동물 동반 안내 71곳은 일부 구역·야외 테라스 등의 실제 조건을 함께 봐야 합니다. 접근성 목록 2,098곳 중 상세 안내가 있는 793곳의 항목을 수록했으며, 나머지는 목록 등재 사실만 표시합니다. 무장애 목록 등록만으로 휠체어 출입 가능을 보장하지 않습니다.

위생등급+모범, 관광공사+지자체 소개는 각각 한 주제로 계산합니다. 배지 수는 별점이나 품질 평가가 아닙니다. 주소가 없는 56,062개 기록과 활성 주제가 없는 과거 등재기록 139곳은 검색에서 제외했습니다. 온누리 가맹점 CSV는 소재지가 시도 수준이라 동일 지점을 확인할 수 없어 연결하지 않았습니다.

## 정적 배포와 갱신

사용자의 검색·상세 열람은 저장된 JSON을 사용합니다. 브라우저에는 API 키가 없으며 방문할 때 공공데이터 API 조회 횟수를 사용하지 않습니다. 지도 배경은 OpenStreetMap 온라인 타일을 사용하고, 길찾기는 카카오맵·네이버 지도로 연결합니다.

`data/restaurants.json`은 검색용, `data/details/`는 식당 식별자의 첫 글자별 상세 파일, `data/meta.json`은 출처·자료 범위입니다. 자동 갱신은 없으며, 새 자료를 비공개 수집 환경에서 검토·가공한 뒤 정적 파일을 다시 배포해야 갱신됩니다. 원본 API 응답·수집키·이전 앱의 위반 이력은 이 공개 앱에 포함하지 않습니다.
